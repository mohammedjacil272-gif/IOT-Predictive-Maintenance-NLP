# Fusion dataset-builder readiness

The builder consumes 64-D sensor and 768-D text vectors and preserves canonical keys, provenance, timestamps, cutoff exclusions, modality presence, and entity split metadata. Synthetic fixture tests validate interface behavior. Genuine training was not started.

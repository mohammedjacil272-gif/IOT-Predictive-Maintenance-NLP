# Final sensor model report

The frozen FD001 baseline uses 17 ordered features, 30 consecutive cycles, train-fitted StandardScaler and the existing LSTM checkpoint. Runtime validation rejects missing/unexpected/forbidden fields, non-finite values, duplicate or gapped cycles, mixed units and short windows. The API returns `sensor_only`, model ID, unit, window bounds and prediction semantics. Official FD001 test evaluation was not run during this verification phase. Any previously reported test metrics are retained only as historical documentation and have not been independently reproduced or verified against the current artifact set. The official test labels were not used for training or validation.

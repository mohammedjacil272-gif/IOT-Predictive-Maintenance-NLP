# Desktop architecture

Windows-first desktop architecture: Tauri 2 shell, React/TypeScript/Vite frontend, existing Python FastAPI backend as a loopback sidecar, and existing SQLite/ML/NLP services. The frontend uses real backend contracts for machines, assistant analysis, history and fusion readiness. Rust/Cargo, Tauri CLI, WebView2 and PyInstaller were supplied and an x64 NSIS installer was built on 2026-11-10; clean-machine installation remains unverified.
